Language guide

StatementMeaningRule
PEN BLUE;Set the pen colourMust be a known colour
MOVE 100;Go forward (negative = backward)-1000 to 1000
TURN 90;Turn right (negative = left)-360 to 360 degrees
WIDTH 3;Set the line thickness1 to 20
PENUP; / PENDOWN;Stop / start drawing while moving
LET size = 50;Declare a named constantDeclare once per scope, before use
REPEAT 4 { ... }Run the block several timesWhole number, 1 to 1000
# textCommentIgnored by the compiler

Values can be expressions: MOVE size * 2 + 10;   TURN 360 / 5;   MOVE -(size);

Colours:

The turtle starts in the middle, facing up, with a black pen of width 2 that is down.
